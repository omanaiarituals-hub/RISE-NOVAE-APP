NOVAÉ Finance — PATCH 11.6
Cycles de paie + charges obligatoires + recommandations réalistes

AFFICHAGE ANALYSE
- roue par cycle de paie (jour défini dans Finance) ;
- navigation cycle précédent / suivant ;
- vue secondaire « Cumul annuel » ;
- récap : revenu, charges fixes réservées, provisions, dépenses variables, reste pilotable ;
- détail cliquable des catégories conservé ;
- bloc charges fixes « à confirmer » / « confirmées ».

LOGIQUE OBLIGATOIRE D'ABORD
- seules les charges récurrentes confirmées par l'utilisateur (source=user)
  sont sanctuarisées dans les calculs ;
- une récurrence détectée n'est jamais déduite automatiquement ;
- bouton « Confirmer obligatoire » ou « Ignorer » ;
- une décision utilisateur est protégée contre les réanalyses futures ;
- le forecast / disponible réel ne réserve plus les récurrences non confirmées.

NOVA / RECOMMANDATIONS
Formule de référence :
revenu de référence
- charges fixes confirmées
- provisions mensuelles
- plancher de sécurité
= reste pilotable

Puis :
reste pilotable
- budgets d'enveloppes déjà existants
= marge pour nouvelles propositions

- les nouvelles enveloppes sont plafonnées à cette marge ;
- les objectifs mensuels utilisent uniquement le reliquat restant ;
- Nova ne crée/modifie toujours rien sans confirmation explicite.

Aucune migration Supabase.
Aucun paiement / virement.
