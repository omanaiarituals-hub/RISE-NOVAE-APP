# Patch 8.1 — Analyse catégories

Ajoute une lecture visuelle des dépenses catégorisées dans `/finances/analysis`.
Le donut agrège uniquement les natures de dépenses et sépare `Non catégorisé`.
Un clic sur une catégorie affiche son montant, son pourcentage, son nombre d'opérations et les transactions correspondantes, chacune ouvrant son écran de correction.
Les récurrences affichent désormais le nombre de séries détectées, avec le nombre d'opérations appartenant à ces séries en information secondaire.
La prochaine date d'une récurrence est avancée jusqu'à une date strictement future.
